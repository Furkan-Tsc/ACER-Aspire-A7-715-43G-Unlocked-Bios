# ACER Aspire A7 715 43G Unlocked Bios

This repo contains a BIOS I modded myself for the Aspire A7 A715-43G. Thanks to this unlocked BIOS, we can access the BIOS menu used by developers so that is, the Advanced tab.

## How to flash bios?

When I try to read chip (Winbond 25Q128JW)  with CH341A, I got different chip id. At this point disconnect battery and plug adapter then power on laptop. And yes power on laptop and touch nothing. Try to read chip id it's working always same chip id. And ready for flash.
